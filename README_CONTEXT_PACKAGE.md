# Context package — Multimodal AI Hackathon 2026

## Files
- `HACKATHON_CONTEXT.md`: master source of truth. Use it in every new chat and coding-agent session.
- `CLAUDE.md`: Claude Code instructions; points Claude to the master context and the working protocol.
- `AGENTS.md`: shared rules for Codex and other agents that support AGENTS.md.
- `GEMINI.md`: Google Antigravity instructions.
- `NEW_CHAT_HANDOFF.md`: paste this into a new ChatGPT chat and attach `HACKATHON_CONTEXT.md`.

## Setup
1. Copy these files into the root of the project repository.
2. Open that folder in Claude Code, Codex, or Antigravity.
3. Start the agent and ask it to summarize the current context and identify the next small task before writing code.
4. In a new ChatGPT conversation, attach `HACKATHON_CONTEXT.md` and use the prompt in `NEW_CHAT_HANDOFF.md`.
5. Keep the master context in sync with verified decisions and results. It is a living document, not a guarantee that event facts remain current.
